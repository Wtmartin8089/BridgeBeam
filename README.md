# BridgeBeam

Cross-platform encrypted file sharing app for Android and iPhone.

## Features
- Peer-to-peer file sharing via WebRTC
- Progressive Web App (PWA) - works offline
- QR code sharing for easy device connection
- No file size limits
- End-to-end encrypted transfers
- Works on Android, iPhone, and Desktop

## Technology Stack
- Frontend: Vanilla JavaScript PWA
- Backend: FastAPI (optional for signaling)
- File Transfer: WebRTC DataChannel
- Encryption: Web Crypto API
